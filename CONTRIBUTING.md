# Contributing

Please submit high-quality Gemini Omni prompt cases with visible prompt-to-video evidence.

## Guidelines

- Include the full reusable prompt text when available.
- Include a public source URL and creator attribution.
- Include output video or a link to the original post containing the video.
- Mark reference media separately from final output media when possible.
- Keep entries curated, non-duplicate, and useful for prompt learning.
